# Expense Tracker V3

Modern responsive web version of the Expense Tracker.

## Features
- Add, edit and delete transactions
- Income and expense tracking
- Search and filters
- Monthly budget and progress
- Donut chart analytics
- Top category, largest and average expense insights
- CSV import/export
- Responsive dark UI
- Candara-style typography
- Local browser storage
- Vercel-ready static deployment

## Tech
HTML, CSS, JavaScript, localStorage and Canvas API.

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Vercel
Import this folder/repository into Vercel as a static project. No build command is required.

## Data
Transactions are stored in the browser's localStorage. They are tied to the current browser/device. Use CSV Export to create a backup and Import to restore it.

## Shortcuts
Ctrl+N = new transaction
Ctrl+F = search
Esc = close dialog
